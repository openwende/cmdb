# CMDB 功能开发路线图

基于 bk-cmdb 功能对比分析，按重要优先级排序的开发清单。

---

## 阶段一：生产就绪（P0 - 必须）

### 1.1 权限管理系统
**优先级**: 🔴 最高
**预估工作量**: 3-5 天
**说明**: 生产环境必需，控制谁能访问和修改什么资源

**功能点**:
- [ ] RBAC 角色模型设计
- [ ] 用户-角色-权限关联
- [ ] 资源级权限（业务、集群、模块、主机）
- [ ] 操作级权限（查看、创建、编辑、删除）
- [ ] API 权限中间件
- [ ] 权限缓存机制

**数据模型**:
```
User → UserRole → Role → RolePermission → Permission → Resource
```

---

### 1.2 事件订阅与推送
**优先级**: 🔴 最高
**预估工作量**: 2-3 天
**说明**: 与监控、ITSM、自动化系统对接的关键能力

**功能点**:
- [ ] 事件类型定义（create/update/delete/relation）
- [ ] 订阅管理 API
- [ ] Webhook 推送机制
- [ ] 消息队列支持（可选：Kafka/RabbitMQ）
- [ ] 推送重试机制
- [ ] 推送日志和监控

**API 设计**:
```
POST   /api/v1/event-subscriptions          # 创建订阅
GET    /api/v1/event-subscriptions          # 订阅列表
PUT    /api/v1/event-subscriptions/:id      # 更新订阅
DELETE /api/v1/event-subscriptions/:id      # 删除订阅
GET    /api/v1/event-subscriptions/:id/logs # 推送日志
```

---

### 1.3 服务模板
**优先级**: 🔴 高
**预估工作量**: 1-2 天
**说明**: 标准化模块创建，提高一致性和效率

**功能点**:
- [ ] 服务模板 CRUD
- [ ] 模板包含：模块配置 + 进程模板
- [ ] 从模板创建模块
- [ ] 模板版本管理
- [ ] 模板同步到已创建的模块

**数据模型**:
```
ServiceTemplate
├── name
├── description
├── service_type
├── process_templates[]
└── created_at
```

---

## 阶段二：核心增强（P1 - 重要）

### 2.1 进程管理
**优先级**: 🟠 高
**预估工作量**: 2-3 天
**说明**: 完整资源管理三元素之一（主机、进程、通用对象）

**功能点**:
- [ ] 进程模板定义
- [ ] 进程实例管理
- [ ] 进程与主机/模块绑定
- [ ] 端口管理
- [ ] 启动命令和参数

**数据模型**:
```
ProcessTemplate (进程模板)
├── name
├── start_command
├── stop_command
├── port_list
├── work_path
└── user

ProcessInstance (进程实例)
├── template_id
├── host_id
├── module_id
├── bind_ip
├── port
└── status
```

---

### 2.2 集群模板
**优先级**: 🟠 高
**预估工作量**: 1-2 天
**说明**: 批量创建标准化集群，快速复制环境

**功能点**:
- [ ] 集群模板 CRUD
- [ ] 模板包含多个服务模板
- [ ] 从模板创建集群（含所有模块）
- [ ] 模板版本管理

**依赖**: 服务模板

---

### 2.3 资源目录（资源池）完善
**优先级**: 🟠 中高
**预估工作量**: 1-2 天
**说明**: 完善资源分配和回收机制

**功能点**:
- [ ] 多级资源目录
- [ ] 目录权限控制
- [ ] 资源分配到业务
- [ ] 资源回收到目录
- [ ] 资源申请/审批流程（可选）

---

### 2.4 主机身份
**优先级**: 🟠 中
**预估工作量**: 1 天
**说明**: 主机的唯一标识和认证信息

**功能点**:
- [ ] 主机身份生成
- [ ] Agent Key 管理
- [ ] 身份验证 API
- [ ] 身份轮换机制

---

## 阶段三：效率提升（P2 - 改进）

### 3.1 全文搜索
**优先级**: 🟡 中
**预估工作量**: 2-3 天
**说明**: 大规模数据下的快速检索

**功能点**:
- [ ] Elasticsearch 集成
- [ ] 跨模型搜索
- [ ] 搜索建议（自动补全）
- [ ] 高级过滤语法
- [ ] 搜索结果高亮
- [ ] 增量索引同步

**依赖**: Elasticsearch

---

### 3.2 主机快照
**优先级**: 🟡 中
**预估工作量**: 1-2 天
**说明**: 配置历史和变更追踪

**功能点**:
- [ ] 定期自动快照
- [ ] 手动创建快照
- [ ] 快照对比（Diff）
- [ ] 快照查询和导出
- [ ] 快照保留策略

---

### 3.3 自动发现规则
**优先级**: 🟡 中
**预估工作量**: 2-3 天
**说明**: 减少手动录入，提高数据准确性

**功能点**:
- [ ] 发现规则配置
- [ ] Agent 数据上报接口
- [ ] 数据匹配和合并策略
- [ ] 冲突处理（覆盖/忽略/人工确认）
- [ ] 发现日志

---

## 阶段四：生态扩展（P3 - 扩展）

### 4.1 云资源同步
**优先级**: 🟢 中低
**预估工作量**: 3-5 天/云平台
**说明**: 自动同步云平台资源

**支持平台**:
- [ ] 腾讯云
- [ ] 阿里云
- [ ] AWS
- [ ] Azure（可选）

**同步资源**:
- [ ] 云主机 (ECS/CVM/EC2)
- [ ] VPC 和子网
- [ ] 安全组
- [ ] 负载均衡（可选）

---

### 4.2 容器管理
**优先级**: 🟢 低
**预估工作量**: 5-7 天
**说明**: 云原生资源管理

**功能点**:
- [ ] Kubernetes 集群接入
- [ ] Namespace 管理
- [ ] Workload 管理（Deployment/StatefulSet/DaemonSet）
- [ ] Pod 查看
- [ ] 容器拓扑展示

**依赖**: Kubernetes API

---

### 4.3 API 网关集成
**优先级**: 🟢 低
**预估工作量**: 1-2 天
**说明**: 统一 API 管理和限流

**功能点**:
- [ ] API 限流
- [ ] API 版本管理
- [ ] 调用统计
- [ ] OpenAPI 文档生成

---

## 开发计划建议

### 短期（1-2 周）
完成阶段一，达到生产就绪：
1. 权限管理系统
2. 事件订阅与推送
3. 服务模板

### 中期（3-4 周）
完成阶段二，核心功能增强：
4. 进程管理
5. 集群模板
6. 资源目录完善
7. 主机身份

### 长期（1-2 月）
根据实际需求选择性实现阶段三、四功能。

| 云同步 | 各云厂商 SDK |
| 容器管理 | Kubernetes client-go |
