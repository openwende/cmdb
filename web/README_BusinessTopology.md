# 业务拓扑功能说明

## 功能概述

业务拓扑包含三个主要功能模块：
1. **主机列表** - 显示和管理主机信息
2. **服务实例** - 管理服务实例和进程
3. **节点信息** - 查看和编辑节点基础信息

## 文件结构

```
src/pages/Business/BusinessTopology/
├── index.tsx                 # 主入口文件，包含Tab切换
├── HostList/
│   └── index.tsx            # 主机列表组件
├── ServiceInstance/
│   └── index.tsx            # 服务实例组件
└── NodeInfo/
    └── index.tsx            # 节点信息组件
```

## 主要功能

### 主机列表 (HostList)
- **操作栏功能**：
  - 新增：只有选中模块类型节点时才可用
  - 分配到：包含"业务空闲机池"和"主机池其他目录"选项
  - 编辑：包含"批量编辑"和"导入编辑"选项
  - 复制：支持多种复制操作
  - 更多：扩展操作菜单
- **表格功能**：
  - 支持行选择
  - 显示主机ID、内网IP、管控区域、业务拓扑等信息
  - 支持编辑和删除操作
- **分页**：使用自定义分页组件

### 服务实例 (ServiceInstance)
- **视图切换**：支持"实例"和"进程"两种视图
- **表格功能**：
  - 可展开收起的表格结构
  - 实例视图：显示实例名称、进程数量、标签等
  - 进程视图：显示进程名称、进程ID等
- **操作功能**：
  - 查看进程：显示进程详细信息
  - 添加进程：添加新的进程实例
  - 编辑进程：编辑现有进程配置
  - 删除进程：删除进程（带确认弹框）
- **抽屉组件**：用于查看、添加、编辑进程的详细界面

### 节点信息 (NodeInfo)
- **查看模式**：
  - 显示节点基础信息（创建时间、创建人、模块名称等）
  - 显示服务分类和服务模板信息
- **编辑模式**：
  - 支持编辑模块名称、模块类型
  - 支持编辑主要维护人、备份维护人
  - 支持选择服务分类（二级联动）
- **折叠面板**：使用Collapse组件组织信息结构

## 数据源

所有组件使用的mock数据来自 `src/mock/business.ts`：
- `allHosts2`：主机列表数据
- `serviceInst`：服务实例数据
- `processInst`：进程实例数据
- `processInfo`：进程信息数据
- `processDetail`：进程详细数据
- `nodeInfo`：节点信息数据
- `serviceTemplate`：服务模板数据
- `serviceCategoryMock`：服务分类数据

## 技术栈

- **React 18**
- **Ant Design 5.25.2**
- **TypeScript**
- **自定义分页组件**：`src/components/common/Pagination`

## 使用方式

```tsx
import BusinessTopology from './BusinessTopology';

// 在页面中使用
<BusinessTopology />
```

## 注意事项

1. 所有下拉按钮都带有箭头，点击后箭头方向会改变
2. 表格选择状态会影响操作按钮的禁用状态
3. 所有删除操作都有确认弹框
4. 分页器使用项目自定义组件，支持页码和页大小切换
5. 服务分类支持二级联动选择
6. 所有表单验证都使用Ant Design的Form组件
