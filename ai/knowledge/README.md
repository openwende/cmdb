# 知识库语料

调查助手的 `search_knowledge` 工具从这里检索领域知识。这个说明文件本身不入库。

## 写法约定

- 每篇文档的 `title` 是引用名，每个 `##` 小节是一个检索单元，引用格式为 `[doc=<title>#<小节标题>]`，例如 `[doc=主机流转规则#回收到资源池]`。
- 每个小节要能单独读懂：被单独检索出来时，不依赖上一节的上下文（主语写全，不写"如上所述"）。
- 同一条事实只写在一个小节里，别处需要时写"见《文档名》的某某小节"，避免检索时出现多个"正确段落"。
- **以代码为准**。现有的后端 / 前端文档有不少是旧设计，和代码矛盾时按代码写；来源列在 frontmatter 的 `sources` 里（不入库）。
- "设计上的规则"和"后端实际行为"不一致时两样都写，并写明哪个是界面限制、哪个是后端行为。
- **不写具体的主机名、IP、记录号、演示业务名**：这些是评测题的答案，知识库只写一般规律。
- 系统里没有定义、由 Claude 推断的内容（目前是自定义字段的含义），在 frontmatter 的 `note` 里写明哪些是推断的。
