# 资源类型

## 资源类型是什么

"资源类型"页面管理 CMDB 里有哪些类型的对象，以及每种类型有哪些字段（类型也叫模型）。系统内置四种类型：业务（business）、集群（set）、模块（module）、主机（host）。管理员和编辑者还可以新建资源类型、给类型分组。

## 主线类型

业务、集群、模块三种内置类型是"主线类型"，它们按层级组成业务拓扑：业务 → 集群 → 模块（见《拓扑与空闲机池》）。主机不是主线类型，它不在拓扑里占一层，而是挂在模块上，一台主机可以挂在多个模块。新建的资源类型也可以开启主线能力，插到拓扑里，但目前不能挂在模块下面。

## 页面上的字段定义和主机实际数据

资源类型页面上列出的字段定义，是沿用蓝鲸的一套字段（带 bk_ 前缀，例如 bk_host_innerip），和主机实际存储、工具返回的字段不是一回事：主机类型在这里只定义了主机 ID、主机名、内网 IPv4、内网 IPv6、管控区域 ID 五个字段，而主机实际还有 CPU、内存、磁盘、操作系统、状态等内置字段（见《主机内置字段》）；主机上的 SLA、备份、标签等自定义字段在这里也没有定义（见《自定义字段约定》）。

所以判断主机有哪些字段、字段是什么意思，以主机内置字段和自定义字段的说明为准，不要以资源类型页面上的字段列表为准。在资源类型页面上增删主机字段，不会改变主机实际存储的字段。

## 新建的资源类型

新建的资源类型（例如交换机、数据库实例）有自己的实例数据和字段，但目前和主机是分开的：主机不能和这些实例建立关联，调查助手也没有查询这些实例的工具。问到这类资源时，助手只能说明本次查询无法获得，建议到资源类型页面查看。
